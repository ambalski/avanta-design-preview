# Аванта — тестовый дизайн сайта

[Главная v01](https://ambalski.github.io/avanta-design-preview/v01/) · [Дизайн-система](https://ambalski.github.io/avanta-design-preview/v01/design-system.html) · [Материалы и источники](https://ambalski.github.io/avanta-design-preview/v01/sources.html)

Версия 01, 12 октября 2026. Главная из 14 блоков, дизайн-система с компонентами и состояниями, карта происхождения материалов. Исходники — HTML, CSS и JavaScript в `v01/`.

Статус: «Сайт в разработке». Формы демонстрационные: сетевой отправки и сохранения данных нет. Неподтверждённые сведения и предложенные формулировки указаны в прототипе.

Существующие фотографии, логотип и материалы взяты из сохранённого архива avanta.ru. В `asset-manifest.json` и `content-map.json` указаны происхождение и контекст. Сведения архива сохраняют даты событий.

Шрифт Manrope размещён локально; лицензия SIL OFL — `v01/assets/fonts/OFL-Manrope.txt`. Внешние зависимости и сборка отсутствуют.

Для локального просмотра: `python3 -m http.server 20000 --bind 127.0.0.1` в корне репозитория.
