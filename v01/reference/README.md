# Аванта — вайрфреймы сайта

[Открыть прототип](https://ambalski.github.io/avanta-wireframes/)

Структура 13 страниц для обсуждения с заказчиком. Версия 01, 8 октября 2026.

## Комплект

- P01–P13: 1440 px для компьютера и 390 px для телефона.
- P10: состояния до и после конференции на обеих ширинах.
- Всего 28 макетов в разделе «Комплект»; дополнительные состояния доступны над макетом.
- Карта навигации, семь сценариев, общие компоненты, 12 вопросов для согласования.
- Меню, карточки, фильтры, выбор программы и формата партнёрства, формы и повтор отправки работают в браузере.

Формы имитируют отправку. Серверная обработка, аналитика и сохранение введённых данных не подключены. Неподтверждённые сведения обозначены в макетах.

## Редактирование

Статические HTML, CSS и JavaScript, без сборки и внешних зависимостей.

| Файл | Назначение |
|---|---|
| `index.html`, `viewer.css`, `viewer.js` | Оболочка для просмотра и обсуждения |
| `prototype.html`, `wireframe.css`, `app.js` | Страницы, адаптивная вёрстка, взаимодействия |
| `content.js` | Состав страниц, навигация, состояния, сценарии и вопросы |
| `manifest.json` | Перечень 28 макетов и прямые ссылки |

Для локального просмотра запустите HTTP-сервер в этом каталоге, например `python3 -m http.server 20024 --bind 127.0.0.1`, и перейдите на `http://127.0.0.1:20024/`.

## Источники и статус решений

Обязательные решения: все 13 страниц, преподавание внутри P07, единый путь вступления в клуб и ассоциацию. Состав блоков и сценарии следуют брифу от 8 октября. Предложения по взаимодействиям собраны в разделе «Вопросы и решения».

Подтверждённые сведения конференции: [действующий лендинг](https://leadership.avanta.ru/). Вышедшая книга: [карточка Литрес](https://www.litres.ru/book/mariya-aksenova/znaem-li-my-russkiy-yazyk-21614936/). Проверены 8 октября 2026.

Остальные карточки используют явные плейсхолдеры и примеры для макета. Окончательный визуальный стиль и редакционные тексты требуют согласования.
